# Spec

Implemented the backend scan API and NIST-aligned report builder around the threat council.

- `report.py` builds a 1-10 risk score. The score is labeled `confirmed_cvss` when a version-matched CVE has a numeric CVSS value; otherwise it is labeled `heuristic`. Identical findings are counted once. The report still lists passed/failed tools, CVEs tried and matched, and an after-action plan. `render_pdf` turns that report into a PDF file.
- `fastapi.py` exposes `/health` (includes Zetaris/Meterless engine status and whether the council model key is set), `/tools`, `/cves`, `/verify/url`, `/verify/source`, `/scan/url`, `/scan/source`, and `/report/pdf`. URL scans require `ownership_token` after the site publishes it at `/.well-known/cyber-risk-verify.txt`. Source scans refuse a labeled owner that does not match; an upload with no owner label continues. `ownership_token` is optional unless `cyber-risk-owner.txt` is present. Scan routes accept `format=json` (default) or `format=pdf`. `POST /report/pdf` accepts an existing report and returns `cyber-risk-report.pdf` as an attachment. The temporary scan page and `/static` routes were removed.
- `main.py` starts the API on 127.0.0.1:8000 without shadowing the FastAPI package.
- URL scans perform a single GET and inspect the response, after ownership is proven and the host passes the public-address check. That GET records TLS protocol and certificate expiry when the socket exposes them. Uploaded source is read, not executed, including Dockerfiles, Terraform, and YAML. A mismatched owner label refuses the scan before the agents run. Stay-inspect mode is off unless the request sets `stay_inspect` and `override_command`. When both are set, only preloaded checks run.
- Scans are driven by the parallel Meterless council with debate-manager collision control. The council starts from the preloaded checks and can apply other named inspection methods to the same collected response or source. CVE intel is cross-checked across CISA KEV, NIST NVD, and OSV.

`backend/test_backend.py` covers the report score/narrative/AAR, PDF rendering, arsenal, council, debate manager, Zetaris read-only guard, Scout routing, multi-source CVE merge, API health, and the PDF download routes.
