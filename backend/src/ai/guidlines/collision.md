# Parallel collision guidelines

Council agents propose in parallel. The debate manager resolves collisions.

1. Duplicate tool votes are a collision: keep the strongest reasoned vote and
   free the slot for an overlooked attack surface.
2. Contradictory stances without reasoning are invalid; drop or quarantine them
   until a reasoned argument appears.
3. Prefer unused arsenal tools that cover gaps nobody voted for when slots remain.
4. Never run the same tool twice in one session unless findings explicitly call
   for a re-check.
5. Record every collision and resolution in local debate storage so later rounds
   keep agent context.
